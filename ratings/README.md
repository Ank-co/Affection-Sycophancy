# Human manipulation check

Do people read the affective sentences at the intended levels? Results:
[court/RESULTATS.md](court/RESULTATS.md) (three raters, 60 sentences, Krippendorff's alpha 0.83, levels in the
intended order; control C read as mildly warm, 1.43 on 0–4).

| Path | Content |
|---|---|
| [court/](court/) | the version actually run: three paper questionnaires (A, B, C), transcribed answers, answer key, analysis code and output |
| `Evaluation_01.xlsx` … `05.xlsx`, `Cle_items_NE_PAS_ENVOYER.xlsx`, `items_key.csv` | the first, longer version (420 sentences), prepared but replaced by the short one; instructions in French in [LISEZMOI.md](LISEZMOI.md) |

Raters are anonymous. The answer keys were kept from the raters during the ratings; they are published now that the
check is complete.
